# seed — файлы заявок для импорта

Сюда кладётся JSON-массив заявок для импорта (например, `tickets.json`); формат —
раздел «Импорт заявок из JSON» в `README.md`. При первом старте с пустой базой панель
сама импортирует файл из `SEED_PATH` (по умолчанию `seed/tickets-2026-10-12.json`);
повторный импорт — `uv run python -m app.importer`.

Реальные заявки в репозиторий не коммитятся: всё в этой папке, кроме этого файла,
исключено в `.gitignore`.

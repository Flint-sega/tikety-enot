# Свои темы оформления

[English version](themes.en.md)

В панели три темы: «Ночь» (id `new`), «Классика» (id `classic`) и «Табло» (id `tablo`). Тема целиком задаётся CSS-переменными (токенами) в одном файле, `static/tailwind.css`. Сборщика нет: правите файл, обновляете страницу и сразу видите результат.

Есть два пути. Перекрасить существующую тему проще: правится один файл. Добавить ещё одну тему в список выбора дольше, потому что её id нужно прописать ещё в нескольких местах (список ниже).

## Как устроены темы

В начале `static/tailwind.css` лежат три блока:

```css
:root,
:root[data-theme="classic"] { /* токены Классики */ }

:root[data-theme="new"] { /* токены Ночи */ }

:root[data-theme="tablo"] { /* токены Табло */ }
```

Сервер ставит на `<html>` атрибут `data-theme` с id темы пользователя, и браузер берёт значения из нужного блока. Все компоненты (шапка, карточки, кнопки, чипы, формы) читают только переменные, поэтому одна правка токена меняет цвет везде.

Главное правило: темы различаются **только значениями токенов**. Не пишите правила вида `[data-theme="new"] .card { … }`. Такие перекраски уже ломали старые темы, и тест `tests/test_theme.py` их запрещает.

Классика стоит на `:root`, то есть она запасная тема. Если в вашей теме какой-то токен не задан, он возьмётся из Классики. Поэтому новую тему можно начинать с десятка переменных.

## Какие токены за что отвечают

| Группа | Токены | Где видно |
|---|---|---|
| Шрифты | `--font-sans`, `--font-mono` | весь текст панели; моноширинный — номера заявок и код |
| Страница | `--bg`, `--bg-image*`, `--on-bg`, `--on-bg-muted` | фон за рабочей колонкой и текст прямо на нём |
| Шапка | `--top`, `--top-border`, `--top-text`, `--top-muted`, `--top-tab` | верхняя полоса с вкладками |
| Поверхности | `--surface`, `--surface-2…4`, `--panel`, `--page-surface` | карточки заявок, формы, панели админки |
| Текст | `--text`, `--text-soft`, `--text-muted`, `--text-faint`, `--placeholder` | основной и второстепенный текст на карточках |
| Поля | `--field`, `--field-text`, `--border*` | инпуты, рамки, фокус |
| Главные кнопки | `--btn-primary`, `--btn-primary-hover`, `--on-primary` | «Новая», «Сохранить», «Войти» |
| Кнопка «Закрыть» | `--btn-success`, `--btn-success-hover`, `--on-success` | закрытие заявки |
| Срочность | `--stripe-overdue`, `--stripe-soon`, `--stripe-later`, `--stripe-none`, `--stripe-closed` | цветная полоска слева на карточке |
| Чипы | `--chip-*` (`red`, `amber`, `green`) | плашка со временем, статусы |
| Номер | `--num-bg`, `--num-text`, `--count-bg`, `--count-text`, `--count-red-*` | значок `№108`, счётчики во вкладках, счётчик просроченных |
| Главная | `--menu-*`, `--board-*`, `--hero-*`, `--raccoon` | плашки разделов, тёмное табло ближайших заявок, фон входа, показывать ли енота |
| Список | `--rail-bg` | подложка точек на рейке времени слева от строк (цвет рабочей области) |
| Ширина колонки | `--page-max`, `--page-surface`, `--page-radius` | рабочая колонка со списком |

Скругления (`--r-card`, `--r-btn` и другие) к теме не относятся. Их задаёт отдельная настройка «Круглые / Прямоугольные» в админке и в профиле.

## Путь 1. Перекрасить существующую тему

Например, сделать в «Ночи» фиолетовый акцент вместо бирюзового:

1. Откройте `static/tailwind.css` и найдите блок `:root[data-theme="new"]`.
2. Поменяйте акцентные токены: `--accent`, `--btn-primary`, `--btn-primary-hover`, `--brand`, `--menu-icon`, `--count-bg`, `--border-focus`. Если кнопка стала светлой, поправьте и `--on-primary`, цвет текста на ней.
3. В `templates/base.html` увеличьте версию стилей: `tailwind.css?v=56` станет `?v=57`. Иначе браузеры пользователей покажут старый файл из кэша.
4. Обновите страницу.

Проверяйте контраст текста и фона. Для обычного текста нужно не меньше 4.5:1. Удобно смотреть в DevTools: кликните по цвету в панели Styles, и браузер покажет коэффициент.

## Путь 2. Добавить новую тему

Допустим, нужна тема «Лес» с id `forest`.

**1. Токены.** В `static/tailwind.css` после блока Табло добавьте:

```css
:root[data-theme="forest"] {
    color-scheme: dark;
    --bg: #0d1a12;
    --on-bg: #e6f2ea;
    --top: rgb(13 26 18 / 0.94);
    --surface: #15281c;
    --text: #e6f2ea;
    --btn-primary: #4caf50;
    --btn-primary-hover: #43a047;
    --on-primary: #08130c;
    /* остальное берётся из Классики, добавляйте по мере надобности */
}
```

И кружок для выбора темы в профиле, рядом с `.swatch-tablo`:

```css
.swatch-forest { background: linear-gradient(135deg, #0d1a12 50%, #4caf50 50%); }
```

**2. Разрешить id на сервере.** В `app/sync.py` допишите тему в кортеж:

```python
VALID_THEMES = ("new", "classic", "tablo", "forest")
```

Неизвестные id сервер не сохраняет и показывает вместо них тему по умолчанию. Поэтому без этого шага выбрать тему не получится.

**3. Переключатель в шапке.** В `static/theme.js` добавьте id в порядок переключения и подписи на обоих языках:

```js
var ORDER = ['new', 'classic', 'tablo', 'forest'];
var LABELS = EN
    ? { new: 'Night', classic: 'Classic', tablo: 'Board', forest: 'Forest' }
    : { new: 'Ночь', classic: 'Классика', tablo: 'Табло', forest: 'Лес' };
```

**4. Списки выбора.** Тема выбирается в двух местах:

- `templates/profile.html`: в список `[('new', _("Ночь")), ('classic', _("Классика")), ('tablo', _("Табло"))]` добавьте `('forest', _("Лес"))`;
- `templates/admin/index.html`: в селект «Тема по умолчанию» добавьте `<option value="forest"…>{{ _("Лес") }}</option>` по образцу соседних.

**5. Перевод.** В `app/locales/en.json` добавьте строку `"Лес": "Forest"`. Тест `tests/test_i18n.py` упадёт, если перевод забыт.

**6. Версии файлов.** В `templates/base.html` увеличьте `tailwind.css?v=…` и `theme.js?v=…`.

**7. Тесты.** Список тем зафиксирован в тестах, чтобы тема не пропала случайно. Допишите id в `THEMES` и в строку с `ORDER` в `tests/test_theme.py`, а также в проверку `VALID_THEMES` в `tests/test_default_theme.py`. Затем запустите:

```bash
make check
```

Дымовой тест откроет все страницы в каждой теме и проверит, что они отдаются.

## Картинки: фон и енот

У Ночи фон входа и главной (`--hero-image`, `--backdrop`) ссылается на `static/hero-bg.webp`, а `--raccoon: block` показывает енота `static/raccoon-hero.webp`. В своей теме можно:

- поставить свою картинку: положите файл в `static/` и укажите его в `--hero-image` и `--backdrop` через `url('/static/имя.webp')`;
- убрать енота: `--raccoon: none`;
- обойтись без картинок, как Классика: `--hero-image: var(--bg-image)`.

Картинки лучше сжимать в WebP. Фон Ночи весит около 83 КБ при ширине 1672 px. На телефоне (до 44rem) Ночь берёт уменьшенный фон `hero-bg-900.webp`, около 35 КБ: токены `--hero-image` и `--backdrop` переопределяются в медиазапросе после блоков тем. Сделайте так же, если ваш фон тяжёлый.

## Свои шрифты

Шрифт — тоже токен. Классика и Ночь берут системные стеки (`--font-sans`, `--font-mono` в блоке Классики), Табло подменяет их на Golos Text и JetBrains Mono. Файлы лежат в `static/fonts/` (woff2, только кириллица и латиница, переменные начертания 400–800 и 400–600, около 100 КБ на все четыре), лицензия OFL рядом (`OFL-*.txt`). Объявления `@font-face` стоят в `static/tailwind.css` сразу после блоков тем; браузер скачивает файл шрифта только когда он нужен тексту на странице, поэтому в Ночи и Классике эти файлы не грузятся. Сторонних адресов (Google Fonts и подобных) в рантайме нет и быть не должно: панель работает в закрытых сетях.

Чтобы дать своей теме другой шрифт: положите woff2 в `static/fonts/` вместе с лицензией, допишите `@font-face` по образцу Golos Text и задайте в блоке темы `--font-sans: "Имя", ui-sans-serif, system-ui, sans-serif;`. Для цифр и номеров — `--font-mono`.

## Если что-то пошло не так

- Тема не применяется: проверьте, что id совпадает во всех местах (CSS, `VALID_THEMES`, `theme.js`, списки выбора). Сервер тихо заменяет неизвестный id темой по умолчанию.
- Цвета старые: не увеличили `?v=` в `base.html`, браузер держит кэш. Помогает и жёсткое обновление (Cmd+Shift+R).
- Какой-то элемент не перекрасился: значит, он берёт токен, который вы не задали, и получает значение из Классики. Найдите элемент в DevTools и посмотрите, какую переменную он читает.

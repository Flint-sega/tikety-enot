# Установка одной командой

Панель «Тикеты Енот v2» ставится одним скриптом: он сам выберет способ (Docker или
нативный), создаст `.env` со сгенерированным ключом сессий и запустит панель.
Нужны только **bash** и **curl** (Docker — по желанию, не обязателен).

## 1. Установка

Распакуйте архив (`tikety-enot-v2-ГГГГММДД.zip`) в любую папку и выполните в ней:

```
bash scripts/install.sh
```

Нужны: **bash, curl, awk** и **openssl либо python3** (ключ сессий). Docker — по
желанию, не обязателен.

Скрипт:

1. Найдёт Docker — поднимет панель в контейнере (`docker compose up --build -d`).
   Нет Docker — не страшно: он поставит `uv` в `~/.local/bin` (официальный
   инсталлер, без sudo и root), поставит зависимости и запустит панель в фоне.
2. Создаст `.env` из `.env.example`, впишет туда сгенерированный ключ сессий
   (`PANEL_SECRET_KEY`) и спросит **логин и пароль первого администратора**
   (пароль — скрытым вводом; символы `#` и кавычки в пароле не допускаются —
   формат `.env` их искажает). Можно пропустить, нажав Enter: тогда первый
   администратор создастся из `.env` при первом старте панели — заполните
   `ADMIN_LOGIN`/`ADMIN_PASSWORD` и перезапустите панель (скрипт это подскажет).
   Уже существующий `.env` скрипт не трогает — повторный запуск безопасен
   (обновит код и зависимости; чтобы обновление вступило в силу, перезапустите
   панель. Данные в `data/` остаются на месте). Архив установки **не содержит**
   папку `seed/` — JSON с заявками для импорта докладывается вручную (раздел 4).
3. Дождётся готовности панели (до 60 секунд) и напечатает её адрес.

Откройте напечатанный адрес (по умолчанию <http://127.0.0.1:8072>) и войдите.
Журнал панели: `docker compose logs -f app` (Docker) или файл `nohup.out` в папке
проекта (нативный режим).

**Порт.** По умолчанию панель слушает `127.0.0.1:8072` и видна только на этой
машине. Для нативного режима порт меняется переменной перед запуском:

```
PANEL_PORT=8097 bash scripts/install.sh
```

В Docker-режиме порт задаётся в `docker-compose.yml` (строка
`"127.0.0.1:8072:8000"`).

## 1а. На хостинг (VPS) с доменом и HTTPS — одной командой

Нужно: сервер с Linux (Ubuntu/Debian), домен с **A-записью на IP сервера**,
открытые порты **80 и 443**, Docker (`curl -fsSL https://get.docker.com | sh`).

```
unzip tikety-enot-v2-ГГГГММДД.zip -d /opt/tikety && cd /opt/tikety
DOMAIN=tickets.example.ru bash scripts/install.sh
```

Скрипт создаст `.env` (спросит логин и пароль администратора), впишет туда
`DOMAIN` и `COOKIE_SECURE=1`, соберёт панель и поднимет рядом **Caddy** — он сам
получит и будет продлевать сертификат Let's Encrypt. Через минуту панель открыта
по адресу `https://tickets.example.ru`. Журналы: `docker compose logs -f app`
(панель) и `docker compose logs -f caddy` (HTTPS).

Обновление на новую версию: распакуйте новый архив поверх (папка `data/` и `.env`
не трогаются) и выполните ту же команду ещё раз, затем
`docker compose --profile https up -d --build` — изменения схемы базы
применятся сами при старте.

## 2. Вариант с Docker (вручную, без скрипта)

```
cp .env.example .env      # впишите ADMIN_LOGIN, ADMIN_PASSWORD, openssl rand -base64 32 → PANEL_SECRET_KEY
docker compose up --build -d
docker compose logs -f app   # дождитесь «Импортировано …» и закройте Ctrl+C
```

Подробности по каждому ключу `.env` — в `README.md`, раздел «Где взять каждый ключ».

## 3. Где что настраивается

| Что | Где |
|-----|-----|
| Токен UseDesk, токен телеграм-бота, chat_id группы | В панели: **Админ → «Ключи и функции»** — ключи вписываются без перезапуска, рядом кнопки проверки «Тест UseDesk» и «Тестовое сообщение». Ключ в админке сильнее значения из `.env` |
| Тема и форма плашек/кнопок | У каждого свои: **Мой профиль** (логин в шапке) или кнопка темы в шапке (Ночь → Классика → Табло). Вид по умолчанию и запрет личного вида — **Админ → «Внешний вид»** |
| Часы в шапке | Первые — время устройства, вторые — часовой пояс: для всех в **Админ → «Внешний вид»**, свой — в **Мой профиль**. На плановое время заявок не влияет (оно по Москве) |
| Шаблоны заявок | Вкладка **«Шаблоны»** — у каждого: личные или «для всех»; там же инструкция «Как сделать шаблон» |
| Пароль | Каждый меняет свой в **Мой профиль**; админ — любому в **«Пользователи»** (не короче 8 символов) |
| Маскот-енот | Встроен в оформление (шапка и страница входа) и не отключается |
| Тумблеры функций (UseDesk, Телеграм, кнопки шаблонов, история по дням) | **Админ → «Функции»** — переключаются без перезагрузки |

## 4. Импорт заявок из JSON (по желанию)

Если есть готовый список заявок (JSON-массив объектов; формат — раздел «Импорт заявок
из JSON» в `README.md`):

1. Положите файл в `seed/`, например `seed/tickets.json`.
2. В `.env` допишите: `SEED_PATH=seed/tickets.json`
3. Импорт (дублей не будет, существующее не перезаписывается):

   ```
   # Docker-режим:
   docker compose up -d
   docker compose exec app /app/.venv/bin/python -m app.importer

   # Нативный режим (из папки проекта):
   uv run python -m app.importer
   ```

## 5. Бэкап и восстановление

Вся база панели — папка `data/` в проекте (файл `tickets.sqlite`); в ней же лежат
вписанные через админку токены, поэтому копии храните как пароли.

Восстановление из копии:

```
# Docker-режим:
docker compose stop app
rm -rf data && cp -R /путь/к/бэкапу/data-ГГГГММДД data
docker compose start app

# Нативный режим: остановите процесс панели, затем замените папку data/
# тем же способом и запустите заново (bash scripts/install.sh или uv run uvicorn app.main:app --host 127.0.0.1 --port 8072)
```
